# Vibe code refactor 


To run this locally




Install dependencies:



Frontend: npm install



Python Backend: Create a virtual environment (optional but recommended): python3 -m venv .venv and activate it: source .venv/bin/activate (Linux/macOS) or .venv\Scripts\activate 


(Windows). Then, install the required Python packages: pip install -r requirements.txt



Set up environment variables: Create a .env file in the project root and define the following environment variables



Start the development servers:



Next.js frontend: npm run dev (This usually starts the frontend server on port 9002)


Genkit development server: npm run genkit:dev or npm run genkit:watch



Access the application: Open your web browser and go to http://localhost:9002.
