# **App Name**: VibeRefactor

## Core Features:

- Code Ingestion: Accept a public GitHub repository URL or ZIP file upload containing Python code for analysis.
- AI-Powered Refactoring Analysis: Leverage an LLM-powered agent (GPT-4 or Gemini) to analyze the ingested Python code, detect code smells and design patterns, and suggest refactoring steps. The agent will use a tool that incorporates information about refactoring.guru.
- Interactive Refactoring Report: Display an interactive report with detected code smells, design patterns, suggested refactoring steps, and a downloadable starter template with a README.

## Style Guidelines:

- Primary color: White or light gray for clean code viewing.
- Secondary color: Dark gray for contrast and code elements.
- Accent: Teal (#008080) to highlight key refactoring suggestions and UI elements.
- Split-screen layout for code viewing and report display.
- Clear and intuitive icons for code smells and design patterns.
- Subtle transitions and animations for a smooth user experience.
